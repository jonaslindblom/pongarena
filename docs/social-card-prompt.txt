Social card design brief

Small brains. Big rallies.
Play Pong. Explore neural networks.

Use the app's cream background, forest-green text, existing mark.svg logo,
Manrope font, vertical court, mint paddle and muted orange opponent.
Include Counter's actual 6 → 6 → 4 → 3 → 3 architecture and 97 parameters.
Keep the scientific lab character: thin grid and connections, minimal glow.

Final asset: public/social-card.png (1200 × 630)
Editable source: scripts/social-card.html
Rendering: Playwright Chromium, 1200 × 630 viewport, deviceScaleFactor 1;
open the HTML using a file URL, await document.fonts.ready, then screenshot.
Requires npm ci for the bundled Manrope font and Playwright.

The final card is rendered from HTML/SVG using actual app assets, replacing
an earlier imagegen concept to match the application identity precisely.
